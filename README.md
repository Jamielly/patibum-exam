## 🪷 sobre o projeto

O **patibum-exam** é o meu repositório pessoal de estudos e preparação para os exames da 42.

Aqui guardo exercícios, soluções e anotações da minha jornada em **C**, com o objetivo de praticar lógica de programação, revisar conceitos importantes e ganhar confiança para as provas.

> Um cantinho para errar, aprender, testar de novo e evoluir um pouquinho a cada dia. 🦢

---

## 🩰 objetivos

- 📚 Revisar os conceitos essenciais de C
- 💻 Praticar os exercícios no formato do exame
- 🧠 Desenvolver raciocínio lógico e resolução de problemas
- ⏱️ Treinar gestão de tempo sob pressão
- 🔁 Reforçar o aprendizado com prática constante
- 🌷 Acompanhar minha evolução ao longo dos estudos

## 🌸 como usar

**Clonar o repositório:**

```bash
git clone https://github.com/Jamielly/patibum-exam.git
cd patibum-exam
```

**Compilar um exercício** (mesmas flags do exame):

```bash
cc -Wall -Wextra -Werror exercicio.c -o exercicio
./exercicio
```

**Verificar a norma** (para os projetos da 42):

```bash
norminette nome_do_arquivo.c
```

## 🎀 dicas para o exame

- 📖 Leia o enunciado com calma, duas vezes, antes de escrever qualquer código
- 🧪 Teste com casos de borda: string vazia, `NULL`, números negativos, `INT_MIN`
- 🧹 Cuidado com **memory leaks** e com o `\0` no final das strings
- ⌨️ Pratique escrever sem autocomplete, como no ambiente da prova
- ✅ Compile sempre com `-Wall -Wextra -Werror` antes de submeter
- 🌬️ Respire fundo: errar faz parte, e o exame pode ser refeito

## 🕊️ filosofia de estudos

> *"Little by little, a little becomes a lot."*

A ideia não é decorar soluções, mas **entender** como cada código funciona, aprender com os erros e desenvolver autonomia para resolver problemas novos.

Cada exercício concluído é mais um passo nessa jornada. ♡
